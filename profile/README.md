## 📌 Guía Rápida e Instructivos para Estudiantes

<details>
<summary><b>🚀 ¿Cómo empezar una práctica en Wokwi y GitHub? (Haz clic para desplegar)</b></summary>

<br>

1. **Clonar el Starter-Kit Oficial:**  
   Abre tu terminal o consola de Git y ejecuta:
   ```bash
   git clone https://github.com/UETS-Soporte-Tecnico/Starter-kit.git
   ```
2. **Crear tu Repositorio Personal:**  
   Crea en tu cuenta personal de GitHub un repositorio llamado `diagnostico-soporte-3bach` (o según la indicación del docente) e importa las carpetas `bloque_1` y `bloque_2`.
3. **Simular en Wokwi:**  
   Abre [Wokwi.com](https://wokwi.com), selecciona la tarjeta **ESP32 DevKit v4** (`board-esp32-devkit-c-v4`) y carga tu archivo `diagram.json` y sketch Arduino.
</details>

<details>
<summary><b>📹 Pautas para la Entrega del Video Sumativo (Metodología MIT)</b></summary>

<br>

- **Formato:** Video grabado en screencast (máximo 4 a 5 minutos).
- **Contenido Requerido:**
  1. Explicación breve del esquema electrónico y conexionado de pines.
  2. Demostración en vivo de la simulación en Wokwi y monitoreo por el `Serial Monitor` (115200 bps).
  3. Explicación de la lógica del código Arduino (`setup`, `loop`, funciones y conversión analógica/digital).
- **Entrega:** Adjuntar el enlace del video en el archivo `README.md` de tu repositorio de GitHub.
</details>

<details>
<summary><b>🔌 Pinout Rápido de Referencia para ESP32 DevKit C v4</b></summary>

<br>

- **LED Rojo:** `GPIO23` (Salida Digital)
- **LED Verde:** `GPIO22` (Salida Digital)
- **Pulsador SW1:** `GPIO4` (Entrada Digital con resistencia Pull-Down 10k $\Omega$)
- **Potenciómetro (ADC):** `GPIO34` (Entrada Analógica ADC1_CH6, rango 0 a 4095)
- **Pantalla OLED / MPU6050:** Bus I2C (`SDA: GPIO21`, `SCL: GPIO22`)
</details>
